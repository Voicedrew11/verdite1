# disc/

Place your own dump of **King's Field (NTSC-J, `SLPS-00017`)** here — the first
King's Field, released only in Japan in 1994. The US "King's Field"
(`SLUS-00158`) is the Japanese *King's Field II*, a different game; that one is
Verdite2. The US "King's Field II" (`SLUS-00255`) is Verdite3.

**Cue/bin:**

```
disc/KingsField1.cue
disc/KingsField1.bin
```

A CHD can be extracted with
`chdman extractcd -i "<image>.chd" -o KingsField1.cue -ob KingsField1.bin`.

Nothing in this directory is committed except this README (see `.gitignore`), and
no game data is distributed with this project.
